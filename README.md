
# 🎬 YouTube‑Clone

Clone simplifié de YouTube, conçu pour reproduire l’expérience de base de la plateforme vidéo avec une interface responsive et les fonctionnalités principales.

---

## 🚀 Démo en ligne

🌐 [YouTube‑Clone en ligne](https://yt-clone-chi-puce.vercel.app/)

---

## ✨ Fonctionnalités

- 🖥 Interface utilisateur inspirée de YouTube  
- ▶️ Lecture de vidéos  
- 🗂 Navigation entre catégories et vidéos  
- 📱 Design responsive pour mobile et desktop

## ⚡ Installation / Utilisation

### Option 1 : En ligne
Accède directement au site : 🌐 [YouTube‑Clone](https://yt-clone-chi-puce.vercel.app/)

### Option 2 : Locale

1. Cloner le projet :
```bash
git clone https://github.com/Sara-Derdak/yt-clone.git
cd yt-clone
````

2. Installer les dépendances :

```bash
npm install
```

3. Lancer le projet en local :

```bash
npm start
```

4. Le projet sera disponible sur [http://localhost:3000](http://localhost:3000)
